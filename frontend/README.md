# Smart Expense Tracker — Frontend

React + TypeScript + Vite frontend. See the [project root README](../README.md) for the full architecture, API overview, and setup walkthrough.

## Quick start

```bash
npm install
npm run dev
```

- App: `http://localhost:5173`
- Optional `.env`: `VITE_API_BASE_URL=http://localhost:8000/api/v1` (already the default)

## Scripts

```bash
npm run dev         # start the dev server
npm run typecheck   # tsc -b --pretty false
npm run lint         # eslint .
npm run build        # production build (tsc -b && vite build)
npm run preview      # preview the production build locally
```
